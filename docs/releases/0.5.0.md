# 0.5.0 · Material desktop and QEMU

The native Qt panel now has a Material 3 inspired interface, saved light/dark/system appearance, three accent colors and compact navigation. The upper-left wordmark has been removed in both wide and compact layouts.

The experimental QEMU desktop runs the supplied MCU2 firmware applications on a replacement Linux kernel. The center, instruments and vehicle visualization use AMD-backed VirGL; VirtualGL shares the GPU with the independent instrument window. Qt provides VM lifecycle controls, previews, driving and steering-wheel inputs, browser cards, camera inputs and replay controls.

WSLg audio now uses a private, bounded output queue and releases the desktop stream during silence. Fixes also cover speed-unit labels, gear readback and held camera frames during paused replay.

**Validation:** Linux 230 tests passed; Windows 205 passed with 25 Linux-only checks skipped. On Debian WSLg with 2026.26.6.1 MCU2, both accelerated displays survived Qt stop/start. Two 30-second tones, a 120-second tone and embedded Chromium audio reached the tested audio path without output-queue drops. These checks do not establish long-session performance or complete firmware feature parity.

**Still experimental:** ICE under QEMU, extended streaming playback/login, map navigation, all vehicle services, complete replay parity and clean-machine VM preparation. The guest image is built locally and is not included in the download.

Choose the Linux archive for native Linux or Debian WSLg; the Windows archive supplies the Windows control panel with a WSL backend. Source and SHA-256 checksums are also provided. See the bilingual README and [QEMU setup guide](../virtual-desktop.md).

**Bring your own Firmware Dump.** No firmware, maps, accounts or extraction instructions are provided.

## 中文

原生 Qt 控制面板采用 Material 3 风格，支持跟随系统、明暗主题、三种强调色和紧凑导航。宽屏及紧凑布局均已移除左上角标识。

实验性 QEMU 桌面通过替代 Linux 内核运行自备的 MCU2 固件应用。中控、仪表及车模使用 AMD VirGL 加速，仪表独立窗口通过 VirtualGL 共用 GPU。Qt 已接入虚拟机启动／停止、双屏预览、驾驶与方向盘输入、浏览器卡片、摄像头和行驶数据回放入口。

WSLg 音频改用独立缓冲与按需输出，静音时释放桌面音频流；同时修复车速单位、挡位回读及暂停回放后的摄像头保帧。

**验证结果：** Linux 230 项通过；Windows 205 项通过，跳过 25 项 Linux 专用检查。2026.26.6.1 MCU2 在 Debian WSLg 中通过双屏加速及 Qt 完整停止／启动检查；两次 30 秒、一次 120 秒音频和车机内 Chromium 声音验证未发生输出队列丢弃。这不代表长时间性能或全部固件功能等效已验证。

**剩余限制：** ICE 的 QEMU 运行、长时间流媒体登录播放、地图导航、全部车辆服务、完整回放等效及干净环境中的虚拟机准备仍待验证。客体系统盘需在本机构建，发行包不包含该磁盘。

Linux 压缩包用于原生 Linux 或 Debian WSLg；Windows 压缩包提供连接 WSL 后端的 Windows 控制面板。另提供源码包与 SHA-256 校验文件。

**Firmware Dump 需要自行准备。项目不提供固件、地图、账号或导出教程。**
